# ฟอนต์ภาษาไทยแบบ Offline (`/public/fonts/`)

ระบบใช้ฟอนต์ตระกูลเดียวคือ **Sarabun** ทั้งหมด และใช้ 3 น้ำหนักเท่านั้น (400 / 500 / 600) ลำดับความสำคัญของข้อความแยกด้วยขนาดและน้ำหนัก ไม่ใช้ฟอนต์หลายตระกูลปนกัน

`@font-face` ตั้งไว้ใน `/frontend/src/index.css` โหลดจากไฟล์ `.woff2` ในเครื่อง (ใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต) เหมาะกับเครือข่ายภายในโรงพยาบาลและหน่วยงานภาครัฐ

| น้ำหนัก | ใช้กับ | ไฟล์ภาษาไทย | ไฟล์ภาษาอังกฤษ/ตัวเลข |
| --- | --- | --- | --- |
| 400 | เนื้อหาทั่วไป | `Sarabun-Regular.woff2` | `Sarabun-Latin-Regular.woff2` |
| 500 | ข้อความเน้น ป้าย ปุ่ม | `Sarabun-Medium.woff2` | `Sarabun-Latin-Medium.woff2` |
| 600 | หัวข้อ ตัวเลข KPI | `Sarabun-SemiBold.woff2` | `Sarabun-Latin-SemiBold.woff2` |
