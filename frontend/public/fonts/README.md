# ฟอนต์ภาษาไทยแบบ Offline (`/public/fonts/`)

ทุกไฟล์โหลดจากในเครื่อง ใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต เหมาะกับเครือข่ายภายในหน่วยงาน
`@font-face` ตั้งไว้ใน `/frontend/src/index.css`

## หน้าจอระบบ: Noto Sans Thai (3 น้ำหนัก 400 / 500 / 600)

| น้ำหนัก | ไฟล์ภาษาไทย | ไฟล์ภาษาอังกฤษ/ตัวเลข |
| --- | --- | --- |
| 400 | `NotoSansThai-Regular.woff2` | `NotoSansThai-Latin-Regular.woff2` |
| 500 | `NotoSansThai-Medium.woff2` | `NotoSansThai-Latin-Medium.woff2` |
| 600 | `NotoSansThai-SemiBold.woff2` | `NotoSansThai-Latin-SemiBold.woff2` |

ที่มา: `@fontsource/noto-sans-thai` (SIL Open Font License 1.1)

## เอกสาร / พิมพ์: TH Sarabun New

`THSarabunNew-Regular` และ `THSarabunNew-Bold` (`.woff` และ `.ttf`) ใช้กับงานพิมพ์ทั้งหมด (`@media print`) และพื้นที่ที่ใส่ class `font-doc` เช่นแบบ สขร. 1
ที่มา: แพ็กเกจ `font-th-sarabun-new` (ฟอนต์ของ สนง.ส่งเสริมอุตสาหกรรมซอฟต์แวร์แห่งชาติ SIPA)

`Sarabun-*.woff2` เป็นฟอนต์เดิม ปัจจุบันไม่ได้ใช้แล้ว
